Getting your iMessage
chat ready.

iMessage doesn't have a built-in export button — but we've made it simple. Run a small script on your Mac and it drops a file on your Desktop, ready to upload. Takes about two minutes.

1
Sync your Messages

Make sure Messages is open on your Mac and your chat history is synced — open Messages, go to Messages → Settings → iMessage, and confirm you're signed in.

2
Download the script

A single Python file. No installation, no third-party apps. Python ships with every Mac — nothing extra to set up.

↓  Download chatbook-imessage.py
3
Open Terminal and run it

Open Terminal — search for it with ⌘ Space then type "Terminal". Run each command one at a time — copy it, paste it in, press Enter, then do the next.

Command 1
cd ~/Downloads
Command 2
python3 chatbook-imessage.py

The script will show you a list of your group chats. Pick one, and it saves a zip file to your Desktop — takes about a minute.

If Terminal asks for Full Disk Access

Go to System Settings → Privacy & Security → Full Disk Access and add Terminal to the list. Then run the command again.

4
Upload your zip and order

The script saves a file called something like Chatbook - Your Chat.zip to your Desktop. Drop it below and we'll carry it straight into the wizard.

Privacy

The script runs entirely on your Mac — your messages never leave your computer during export. The zip it creates is processed on our servers only long enough to produce your book, then permanently deleted. We don't store, share, or read your messages. Full privacy policy →
